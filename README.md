# 원데이 퀘스트

`index.html`을 중심으로 만든 웹 앱입니다. 미션과 기록, 인증샷, 로컬 커뮤니티, 포인트 체험 기능을 포함합니다.

## 날씨 연결

오른쪽 추천 영역은 기상청 단기예보를 우선 사용합니다. 기상청 키가 없거나 응답에 실패하면 Open-Meteo에서 선택한 도시의 현재 기온과 오늘의 최저·최고 기온을 가져옵니다. 날씨 요청은 `api/weather.mjs`에서 처리하며 기상청 서비스키는 브라우저로 보내지 않습니다. 서버 함수가 없는 정적 미리보기에서는 브라우저가 Open-Meteo에 직접 요청합니다.

1. [공공데이터포털의 기상청 단기예보 조회서비스](https://www.data.go.kr/data/15084084/openapi.do) 활용신청을 하고 서비스키를 발급받습니다.
2. Vercel 프로젝트 환경변수 `KMA_SERVICE_KEY`에 **디코딩된 서비스키**를 설정합니다.
3. 프로젝트를 다시 배포합니다.

앱은 전국 85개 시 단위 지역을 시·도별로 선택할 수 있으며, `weather-cities.js`의 도시 대표 좌표를 조회에 사용합니다. 두 날씨 서비스 모두 연결되지 않으면 날씨와 코디는 연결 안내를 보여주고, 식사는 계절을 기준으로 추천합니다. Open-Meteo의 공개 API는 비상업적 사용을 위한 것이므로 상업적으로 운영할 경우 별도 사용 계약과 `OPEN_METEO_API_KEY`가 필요합니다.
